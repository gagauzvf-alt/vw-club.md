# Модель контента

Актуально: 2026-07-26.

Коллекции `articles_ru` и `articles_ro` загружаются из `src/content/articles/{ru,ro}` и локально редактируются через Keystatic.

| Поле | Тип | Обязательно | Назначение |
|---|---|---|---|
| `title` | string | да | H1, карточка, SEO |
| `date` | date | да | дата публикации |
| `model` | string[] | да | создаёт страницы моделей |
| `engine` | string[] | да | связи с агрегатами; может быть пустым |
| `years` | string | нет | диапазон поколения |
| `type` | enum | да | `проблемы`, `обслуживание`, `кейс`, `гайд` |
| `cover` | string | нет | только локальный проверенный медиафайл |
| `description` | string | да | meta description и карточка |
| `draft` | boolean | да | исключает материал из production |

RU и RO версии одной статьи обязаны иметь одинаковое имя файла/slug. Страница модели создаётся автоматически по нормализованному значению `model`.

Пример:

```yaml
title: "Volkswagen Passat B8: базовая проверка"
date: 2026-07-26
model: ["Passat B8"]
engine: []
years: "2014–2023"
type: "гайд"
description: "Краткое точное описание."
draft: false
```
