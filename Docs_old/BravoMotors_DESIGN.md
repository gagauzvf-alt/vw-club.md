## 1. Принципы (что не меняется)

1. **Мгновенная загрузка.** Только системные шрифты, без внешних JS/CSS-зависимостей. Единственный скрипт — инлайновое меню. Изображения WebP + lazy.
2. **Спокойная светлая палитра.** Серый фон-холст, белые карточки-поверхности, светлая полупрозрачная шапка. Оранжевый — **только действия и акценты** (кнопки, фокус, теги), ≤5% площади.
3. **Данные как украшение.** Вместо стоковых картинок — реальные факты в моноширинном наборе: коды моторов (EA888, DQ200), оборудование (ODIS/VCDS/PIWIS/ISTA), годы, телефоны, метки. Декора без смысла нет.
4. **Тон текста** — как в FAQ: честно, спокойно, по делу. Без «лидеров рынка» и восклицательных знаков.
5. **Минимум движения.** Только hover (~150ms) и плавные раскрытия. Никаких каруселей, параллаксов, скролл-анимаций. `prefers-reduced-motion` уважается.

## 2. Токены (`:root` в Layout.astro)

```css
:root {
  --page:         #eef0f3;  /* фон-холст (светло-серый) */
  --card:         #ffffff;  /* поверхности: карточки, шапка-блюр, таблицы */
  --ink:          #1f2328;  /* основной текст */
  --muted:        #7a818a;  /* вторичный текст, метки */
  --line:         #e6e8ec;  /* границы, разделители, сепараторы */
  --orange:       #f26a1b;  /* фирменный, ТОЛЬКО действия/акценты */
  --orange-soft:  #fdeee3;  /* мягкая оранжевая подложка */
  --orange-hover: #e05f12;  /* ховер кнопок */
  --green-soft:   #e7f6ee;  /* редкие статусные подложки */
  --blue-soft:    #eaf0fb;
  --violet-soft:  #f0edfb;
  --shadow:       0 1px 2px rgba(31,35,40,.04), 0 8px 24px rgba(31,35,40,.06);
  --r:            18px;      /* канонический радиус карточек */
  --font-sans:    "Helvetica Neue", Helvetica, -apple-system, "Segoe UI", Arial, sans-serif;
  --font-mono:    ui-monospace, "Cascadia Code", "JetBrains Mono", Consolas, monospace;
}
```

Цветовая модель: **фон `--page` (серый) → карточки `--card` (белые) с `--shadow`**. Тёмных графитовых блоков нет. Текст `--ink`/`--muted`. Границы `--line`. Оранжевый не используется для длинного текста.

## 3. Типографика

Шрифты системные, без загрузки. Базовый текст 17px / line-height 1.6 / `--ink`.

| Элемент | Размер / начертание | Особенности |
|---|---|---|
| H1 (в hero) | 36px / 800 / letter-spacing −.5px | mobile 30px |
| H2 (секции) | 30px / 700 / −.4px | внутри `.about-block` — 22px |
| H3 (карточки) | 16–17px / 700 | |
| Текст | 17px / 1.6 | вторичный 15px `--muted` |
| `.mono` | 13px / letter-spacing .05em | моноширинные технические строки |

**Mono-акценты — фишка дизайна:** брови над заголовками, коды моторов/КПП, метки данных (`.ek` в таблице оборудования — 12px/.08em/muted), телефоны, хлебные крошки, переключатель языков, номера карточек ценностей (`01…07`).

## 4. Компоненты

### Кнопки
- **Primary (`.btn`):** фон `--orange`, белый текст, 16px/600, padding 14px 28px, **radius 999px (пилюля)**, тень `0 6px 16px rgba(242,106,27,.25)`, hover → `--orange-hover`. Текст = действие («Записаться», «Позвонить»).
- **Soft (`.btn-soft`):** белый фон, `--ink`, та же геометрия, `--shadow`, hover — лёгкий подъём (`translateY(-1px)`).

### Шапка (`header`)
Липкая, **полупрозрачная светлая** (`rgba(238,240,243,.88)` + `backdrop-filter: blur(12px)`), нижняя граница `--line`, высота nav 72px. Логотип (`logo-img` 40×40, radius 8px) + меню + телефон mono + кнопка «Записаться» + переключатель языков.
- **Nav-ссылки:** 15px `--muted`, padding 8px 14px, radius 999px (пилюля), hover — белая подложка + тень.
- **Дропдаун «Услуги» (`.drop-menu`):** белый, radius 16px, крупная тень `0 16px 48px rgba(31,35,40,.14)`, **2 колонки**, min-width 260px.

### Переключатель языков
Mono 12px / .08em, `--muted` → `--ink` (активный 700). Разделитель `|` цветом `--line`.

### Хлебные крошки (`.breadcrumbs`)
Слим-полоса под шапкой, mono 12px / .04em, ссылки `--muted` → `--ink`, текущая — `--ink` + `aria-current`, разделитель `/` цветом `--line`.

### Подвал (`footer`)
Светлый (не графит), `--muted` 15px, верхняя граница `--line`. Сетка `2fr 1fr 1fr 1fr` (mobile 2 кол. → 1 кол.). Заголовки колонок `--ink` 15px. NAP, телефоны mono, марки, соцсети.

### Мобильное меню
Бургер 44×44 (radius 10px). Оверлей `rgba(31,35,40,.4)`. Панель справа `min(340px,100vw)`, белая, слайд-ин. Пункты 52px (17px/600), подпункты услуг 48px (15px `--muted`). Закрытие: ✕, клик по оверлею, Esc. Доступность: `inert` на закрытой панели, `aria-expanded`/`aria-hidden`, блок скролла body.

### Паттерны страниц (scoped-стили в файлах страниц — держать единообразно)
- **Hero (`.stub-hero`):** padding 56px 0 44px, тёплый градиент сверху `linear-gradient(180deg,#fdf3ec 0%, var(--page) 70%)`. Внутри: `.eyebrow` + H1 + `.answer-lead` (18px `--muted`, max-width 640).
- **Колонка контента (`.stub-content`):** max-width 780px (лонгриды истории — `.story` 720px).
- **Блок (`.about-block`):** margin-bottom 44px; H2 22px; текст `--muted` 16px/1.65.
- **Таблица оборудования (`.eq-table`):** белая, radius 16px, `--shadow`; строки grid `160px 1fr`; ключ `.ek` mono 12px/.08em `--muted`.
- **Карточка ценности (`.val-card`):** белая, **radius 18px**, `--shadow`, padding 24px; номер `.val-num` mono 12px/.08em; H3 17px/700; текст `--muted` 15px/1.6. Сетка 2 кол. → 1 кол. (≤700px).
- **FAQ (`.faq-item`):** белая, radius 18px, `--shadow`, padding 20px 24px; вопрос H3 16px/700; ответ `--muted` 15px. **Видимые пары вопрос/ответ** (не скрытый аккордеон) — ради извлекаемости ИИ-моделями.
- **Стат-полоса (`.stat-strip`):** 3 карточки; число `.stat-num` 30px/800 `--ink`; подпись 13px `--muted`.
- **CTA-band:** белая, radius 24px, `--shadow`, padding 40px, flex space-between.
- **`.read-more`:** оранжевая ссылка-тизер 600/15px.

## 5. Сетка, отступы, геометрия

- **Контейнер `.wrap`:** max-width 1120px, padding 0 24px (mobile 0 16px).
- **Ритм секций:** `section` padding 64px 0 (mobile 44px 0).
- **Радиусы (иерархия):** пилюли/кнопки 999px · карточки 18px (`--r`) · таблицы/дропдаун 16px · крупные блоки (CTA) 24px · мелкие (бургер, mob-кнопки) 10px · лого 8px.
- **Тени:** карточная `--shadow` · кнопка — оранжевое свечение · дропдаун — глубокая `0 16px 48px`.
- **Брейкпоинты:** 900px (меню → бургер, секции 44px) · 520px (футер в 1 колонку, `.wrap` padding 16px).

## 6. Доступность и качество

- Контраст текста ≥ 4.5:1. Оранжевый не для длинного текста.
- Видимый фокус: `:focus-visible` — обводка 2px `--orange`, offset 2px.
- Touch-таргеты ≥44px; все `tel:` кликабельны.
- Мобильное меню: `inert` + управление `aria-*`, закрытие по Esc.
- `prefers-reduced-motion` — анимации гасятся.
- Цель PageSpeed mobile 95+ (текущий Performance 99; Accessibility 89 — в плане добор по ARIA).
