# Дизайн-система VW Club Moldova

Актуально: 2026-07-26.

## Характер

Технический, инженерный, спокойный и понятный. Сайт не имитирует официальный ресурс Volkswagen и не выглядит витриной сервиса.

## Токены

Источник — `src/styles/tokens.css`.

| Роль | Значение |
|---|---|
| основной синий | `#003B70` |
| интерактивный акцент | `#0077CC` |
| текст | `#1F2933` |
| вторичный текст | `#52616F` |
| мягкий фон | `#F4F7FA` |
| границы | `#D9E2EC` |

Интерфейс использует Inter, длинные материалы — Source Serif 4. Hero строится на типографике и технической карточке без нелицензированных фото.

## Компоненты

- sticky header с текстовым клубным знаком, а не официальным логотипом;
- primary/ghost кнопки с видимым focus;
- карточки статей и моделей;
- светлые информационные секции;
- отдельная синяя секция партнёра;
- breadcrumbs в UI и JSON-LD.

## Адаптивность и доступность

Mobile-first, сетки переходят в одну колонку; изображения и видео сохраняют пропорции; интерактивные элементы доступны с клавиатуры; цвет не является единственным носителем состояния.

## Запрещено

- кольца Audi, официальный VW roundel и чужие слоганы;
- премиальная чёрно-красная тема эталона;
- фиктивные фото, отзывы, рейтинги и цифры;
- агрессивные сервисные CTA выше клубной ценности.
